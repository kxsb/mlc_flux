# MLCFlux bêta v1.0.4 multi

Date : 2026-06-20
Statut : première version officiellement suivie par le système de versionnage du dépôt.

## Résumé

La version `v1.0.4` marque le passage de MLCFlux multi vers une exploitation plus structurée : synchronisation automatique, orchestration multi-instance, page d’entrée plus professionnelle et documentation intégrée des versions.

## Changements principaux

### Synchronisation automatique

La synchronisation peut désormais être déclenchée par tâche planifiée. Ce point change la nature de l’outil : MLCFlux n’est plus seulement une interface consultable après synchronisation manuelle, mais une plateforme qui peut être maintenue à jour de façon régulière.

### Orchestration multi-instance

Un orchestrateur de synchronisation multi-instance a été ajouté afin de traiter les monnaies locales configurées dans un même flux technique.

### Page d’entrée publique

La page de sélection des instances a été retravaillée :

- titre plus sobre ;
- introduction plus compacte ;
- suppression du bandeau intermédiaire “Ouvrir une instance” ;
- chargement plus lisible des cartes d’instances ;
- ajout d’une fenêtre “Notes de version”.

### Versionnage

Cette version introduit le point de départ du versionnage formalisé :

- fichier `VERSION` ;
- fichier `CHANGELOG.md` ;
- dossier `docs/releases/` ;
- futur tag Git `v1.0.4`.

## Versions antérieures

Les versions `v1.0.1`, `v1.0.2` et `v1.0.3` correspondent aux premiers jalons bêta de la branche multi-instance. Elles restent mentionnées dans les notes de version visibles depuis l’interface, mais ne seront pas taguées rétroactivement.
